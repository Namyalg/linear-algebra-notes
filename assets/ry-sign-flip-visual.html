Rotating the $zx$-plane about $y$ by 90°

The 2D engine rotates a frame through the pair (first → second, second → −first). Only the labeling of which physical axis is "first" decides where the minus lands.
A · The geometric move (z is first, x is second)
z → +x and x → −z. The −1 is literally the "second → −first" move: x gets thrown to −z.
B · Where that lands in the matrix (rows read x, y, z)
In the matrix, x is the top row and z is the bottom row. The plane's "first" axis (z) therefore occupies the bottom row, so the −sin shows up bottom-left (z-row, x-column).
Ry(90°) = ⌈ 0 0 1 ⌉    col3 = image of z = (+1,0,0) ✓
        | 0 1 0 |
        ⌊ −1 0 0 ⌋    col1 = image of x = (0,0,−1) ✓
Why it's not arbitrary: the 2D rotation always puts "−sin" at first-row / second-column of its block. For Rz the plane {x,y} matches the matrix rows, so −sin is top-right. For Ry the plane's first axis is z, but z is the bottom matrix row — so −sin moves to bottom-left. The sign tracks the axes; it is never picked by hand.
