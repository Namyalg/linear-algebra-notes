Representing w = (3,5) in two different bases

Both panels split w into "part along v₁" + "part along v₂". The ONLY difference is how easy it is to find the parts.
The idea: superposition happens in every basis. Orthogonality only decides the difficulty — perpendicular axes ⟹ each part is the projection (one dot product, read off alone); slanted axes ⟹ the projection lies, you must solve.
Orthonormal · v₁=(1,0), v₂=(0,1)
a₁ = w·v₁ = 3  |  a₂ = w·v₂ = 5
projection = coefficient, each read off alone ✓
Non-orthogonal · v₁=(2,1), v₂=(1,2)
naive projection on v₁ = 2.2  ≠  TRUE coefficient 1/3
naive projection on v₂ = 2.6  ≠  TRUE coefficient 7/3
axes overlap (not perpendicular) ⟹ must solve the system
a₁v₁ (part from v₁) a₂v₂ (part from v₂) w target v₁,v₂ axes projection drop (perpendicular)
